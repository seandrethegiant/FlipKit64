All files: Ogg Vorbis, 32 kHz stereo, about -24 dBFS RMS (level-matched, so
switching scenes does not jump in loudness), peaks under -1 dBFS.

## Where these come from

Every file is synthesised from scratch by
[`tools/make_ambience.py`](../../../../../../tools/make_ambience.py) (numpy +
ffmpeg). No recordings or samples by anyone else are involved, so the files
are dedicated to the public domain under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
Regenerate with:

```
python tools/make_ambience.py android/soundscape/src/main/assets/ambience --seconds 150
```

The loops are seamless because all filtering is circular (done over the
whole loop in the frequency domain), every modulation completes a whole
number of cycles per loop, and one-shot events wrap around the end.

## Replacing them with recordings

The natural textures (rain, storm, wind, fire, ocean, cave, spaceship,
archive) hold up well. Tavern, city and battle are approximations; real
recordings will sound better. To swap one in, keep the same file name, make
it a seamless 2-5 minute loop, level it to about -24 dBFS RMS, and **update
the table above** with the source URL, author and licence. Licence-clean
sources:

- Freesound.org with the "Creative Commons 0" licence filter
- Sonniss GDC Game Audio Bundles (royalty-free, no attribution; not CC0, note it in the table)
- BBC Sound Effects is **not** OK here (personal/educational licence only)
